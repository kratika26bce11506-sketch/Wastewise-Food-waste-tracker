# WasteWise 🥗♻️

**WasteWise** is a Python-based Food Waste Reduction System that helps users manage household food inventory, track expiry dates, receive alerts for near-expiry items, discover recipes using available ingredients, and estimate money saved by reducing food waste.

## Problem Statement

Millions of households waste food because they forget about items before they expire. WasteWise helps users keep track of food items and encourages timely consumption.

## Features

* Add food items with quantity, unit, expiry date, and price
* Inventory sorted by expiry date
* Near-expiry alerts
* Expired item detection
* Recipe suggestions from available ingredients
* Mark items as used
* Automatic waste logging
* Waste analytics and savings calculation
* JSON data persistence
